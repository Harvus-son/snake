# Jungle Snake 🐍🍌

Браузерная игра «Змейка» на React + Vite.

## Возможности

- Управление змейкой клавишами **WASD** или стрелками.
- Бананы дают **+10 очков** и увеличивают длину змейки.
- Три уровня: Сад, Храм и Вулкан — с разным количеством барьеров.
- Шесть скинов: Лайм, Океан, Ягода, Золото, Призрак и Огонь.
- Отдельные меню главного экрана, скинов и настроек.
- Пауза, перезапуск, выбор скорости, сетка, звуковой сигнал и проход сквозь края.
- Лучший результат сохраняется в браузере через `localStorage`.
- Адаптация для телефонов с экранными кнопками.

## Запуск локально

Нужен установленный Node.js.

```bash
npm install
npm run dev
```

Открой адрес, который покажет Vite в терминале.

## Проверка сборки

```bash
npm run build
npm run preview
```

## Управление

| Клавиша | Действие |
| --- | --- |
| W / ↑ | Вверх |
| A / ← | Влево |
| S / ↓ | Вниз |
| D / → | Вправо |
| Пробел | Пауза |

## Публикация

Проект использует Vite. Для публикации на GitHub Pages настройте базовый путь Vite под имя репозитория (`/snake/`) и подключите автоматическую сборку каталога `dist`. Для собственного домена или публикации в корне домена базовый путь отличается.
